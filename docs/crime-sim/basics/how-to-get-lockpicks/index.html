How to Get Lockpicks in Crime Simulator: Lockpick Set, Bobby Pin and More

Updated: Aug 19, 2026 Version 1.55

If you have been relying on the crowbar for every locked door, you are making every heist louder and slower than it needs to be. Lockpick tools let you open locks silently -- the difference between a clean escape and a police chase. Here is the complete progression for every lockpick tool in Crime Simulator.

Lockpick tool quick reference: Basic Lockpick Set (buy at shop, basic doors) → Bobby Pin (find in runs, advanced locks) → Advanced Lockpicking skill leaflet (tool boxes/garages) → Master Lockpick Set (world bonus reward, master locks).

Lockpick Tool Progression

Crime Simulator has three tiers of lockpick tools, each unlocking progressively harder locks:

Tool Lock Tier How to Get Cost
Lockpick Set Basic locks Buy at shop Shop price
Bobby Pin Advanced locks Find during runs or buy Varies
Master Lockpick Set Master locks World bonus reward Free after unlock

From basic locks to master locks -- the complete unlock path.

The basic lockpick set handles most doors you will encounter in early-to-mid game houses. The bobby pin is required for higher-security doors with deadbolts. Master locks are rare and only appear in specific endgame locations.

Lockpick Set (Basic)

The lockpick set is your starting tool for silent entry. It replaces the loud crowbar on most interior doors.

How to get it: Buy it from the in-game shop. It is available from the start of a new save.

Use it on: Standard interior doors, bedroom doors, storage closets, and most residential locks.

The lockpick set breaks after several uses and must be repaired or replaced. The tool durability guide covers repair vs replace math.

Bobby Pin (Advanced Lockpick)

The bobby pin opens advanced locks that the basic set cannot touch -- reinforced deadbolts, garage locks, and security doors.

How to get it: The bobby pin is not in the starting shop inventory. Two confirmed paths from community reports:

  1. Find it during runs -- bobby pins appear as loot in tool boxes, garage shelves, and similar containers in mid-to-high tier houses. Multiple Reddit reports confirm finding bobby pins in Lakeside Street runs.
  2. Buy from the Truck Store -- some community posts mention the bobby pin becomes available for purchase at the Truck Store after reaching a certain progression point.

If you are doing runs and not finding bobby pins, try higher-tier neighborhoods. The 201 Masters guide on YouTube specifically recommends the bobby pin for Lakeside Street heists where advanced locks are common.

Advanced Lockpicking Skill Leaflet

The bobby pin tool and the Advanced Lockpicking skill are separate systems. The skill leaflet determines what you can use; the tool is what you have equipped.

To unlock the Advanced Lockpicking skill you need:

  • Skill point -- earned by leveling up through completing jobs
  • Advanced Lockpicking Skill Leaflet -- a collectible found in houses

The leaflet spawns in tool boxes, garage shelves, and locked room containers. Community reports note the Advanced Lockpicking leaflet is not guaranteed per run -- some players went 10+ runs without seeing one. The skill leaflets guide has full spawn location details for all leaflet types.

Pro tip from the community: If you read a skill leaflet and it is not the one you wanted, alt-F4 before saving and quitting to preserve your run progress. When you reload, the leaflet will not be consumed from your inventory, so you can keep trying for the right one.

Master Lockpick Set

Master locks are the highest-tier locks in Crime Simulator. They only appear in specific high-security locations.

How to get it: The Master Lockpick Set is a world bonus reward. World bonuses are permanent, account-wide unlocks earned by completing playthroughs. According to community reports, the fastest players unlock it in around 10-15 runs.

The Master Lockpick Set does not cost money -- once unlocked through world bonuses, it is available on all future saves on your account. The world bonus guide covers the full system including which rewards to prioritize.

Lockpick Tool Strategy

Early game (runs 1-10): Buy the basic lockpick set and rely on it for most doors. Save crowbar for reinforced doors you cannot pick yet.

Mid game (runs 10-25): Hunt for the bobby pin in Lakeside Street and similar high-tier areas. Prioritize finding the Advanced Lockpicking skill leaflet so you can actually use it.

Late game (25+): Focus on world bonus progression to unlock the Master Lockpick Set. Once you have all three tiers, every lock in the game is accessible silently.

Quick reference:

  • Basic lockpick set -- buy at shop, handles most doors
  • Bobby pin -- find in runs or buy at Truck Store, opens deadbolts
  • Advanced Lockpicking skill leaflet -- find in tool boxes/garages, unlocks bobby pin usage
  • Master Lockpick Set -- world bonus reward, opens master locks
