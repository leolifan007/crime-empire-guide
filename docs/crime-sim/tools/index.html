Crime Simulator Tools Guide: Every Item Explained

Jun 9, 2026

I spent my first few Crime Simulator runs using nothing but the crowbar on every door. Loud, slow, and got me caught repeatedly. Better tools changed everything.

Prioritize the lockpick set first. It replaces the noisy crowbar on most locked doors and pays for itself within 2-3 heists.

Tool overview:

Crime Simulator has a growing arsenal of tools for breaking in, disabling security, and escaping. Tools break with use and must be repaired or replaced. Choosing the right tool for each job is the difference between a clean score and an arrest.

Lockpick set -- The bread and butter of every heist. Lets you open locked doors silently. Without it, you rely on the crowbar, which is loud and alerts nearby NPCs. A simple rotation mini-game: turn the pick left or right until the lock gives. Higher-quality sets handle tough locks better and take longer to break.

Crowbar -- Your starter tool. Works on doors, windows, and crates. Loud. Use it only as backup or for breaking into non-essential containers. I stopped carrying a crowbar after getting the basic lockpick set.

Flashlight -- Many interiors are dark. Without it, you miss loot in corners and on shelves. A must-have for every run. The pro version has a wider beam and longer battery.

Sleeping gas -- Neutralizes a single NPC silently. I use it when a guard is patrolling a room I need to search. One can per NPC. Do not use it near other NPCs -- they will notice.

Hacking tool -- Unlocked through the Hacking skill leaflet. Opens electronic door locks and security panels. Without it, electronic locks are impassable. The leaflet drops from special loot boxes.

Glass knife -- Cuts glass silently for window entry. Quieter than breaking glass. I use it on houses with alarmed windows.

Cable ties -- Restrain subdued NPCs so they do not wake up and raise alarms. I carry a few for larger houses with multiple NPCs.

Drill -- Opens safes. Slow and noisy. Use only when the safe content justifies the risk. I check the safe value through the job board intel before carrying a drill.

Blowtorch -- Cuts through reinforced doors and gates. Heavy, noisy, slow. Late-game tool for high-security targets.

My buy order:

  1. Basic lockpick set
  2. Flashlight
  3. Sleeping gas (1 can)
  4. Standard lockpick set (when available)
  5. Hacking tool (rush the leaflet hunt)
  6. Cable ties (for larger houses)

For upgrade paths and advanced tools, see the Tool Upgrades guide.

Crime Simulator Tool Upgrades and Advanced Tools

Jun 9, 2026

Basic tools get the job done, but upgraded versions save time, reduce noise, and fail less often. I went from breaking a lockpick every 2-3 heists to going 10+ on the professional set.

The Master Key from Update 1.3 is the best late-game tool investment I have unlocked. It opens most standard locks instantly, dramatically speeding up heists.

Tool quality tiers:

Tier Example Break Rate Repair Cost Unlock
Basic Basic Lockpick High ~$100-200 Starting shop
Standard Standard Lockpick Medium ~$200-350 Rank 2-3
Professional Pro Lockpick Set Low ~$400-600 Rank 4-5
Premium Master Key (1.3) Very Low ~$800+ 1.3 content

Higher tiers unlock larger sweet spots on lockpicking mini-games and generate less noise.

Advanced tools:

Master Key (Update 1.3) -- Opens most standard residential locks instantly without a mini-game. Does not work on electronic locks or high-security safes. I use it on every standard door. Combined with the hacking tool for electronic locks, it covers about 80% of entry points.

Hacking tool -- Unlocked through the Hacking skill leaflet. Opens electronic door locks and security panels. Without this, electronic locks stop you cold. I found my first hacking leaflet in a special loot box inside a house with electronic locks.

Invisibility Tool -- Mentioned in developer previews as an expensive tool that makes you invisible for about 60 seconds. Exact requirements are still being refined by the developer. It may not be in all game versions yet.

Skill leaflet tools:

Some tools require skill leaflet unlocks rather than direct purchase:

  • Advanced Lockpicking: unlocks professional lockpick sets
  • Advanced Hacking: enables the hacking tool for electronic systems
  • Tool Maintenance: reduces tool break rate by about 20-30%
  • Stealth Ops: quieter tool usage across the board

My upgrade priority after basics:

  1. Standard Lockpick Set -- reduces break rate significantly
  2. Pro Flashlight -- wider beam, longer battery
  3. Advanced Hacking -- unlocks electronic entry
  4. Master Key (Update 1.3) -- skip most lockpicking
  5. Tool Maintenance skill -- saves money on repairs long-term

The Tool Maintenance skill pays for itself after about 10 heists. If you play frequently, hunt for this leaflet before spending on expensive premium tools.

Storage tips:

  • Keep at least one backup of each essential tool in your hideout stash
  • Sell broken tools if repair cost exceeds 60% of replacement price
  • Mark houses with electronic locks on the map -- they need the hacking tool, not lockpicks
